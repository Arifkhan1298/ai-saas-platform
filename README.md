# NEXVORA AI — Ultra-Premium Futuristic AI SaaS Website

> **“Intelligence That Moves Your Ideas Forward.”**

A production-grade, portfolio-worthy AI SaaS landing page and interactive product suite built with a **dark luxury futuristic** aesthetic.

---

## ✨ Design & Visual Philosophy

- **Color Palette**: Deep midnight navy (`#030712`, `#060d1f`), layered blue-black gradients, electric blue (`#3b82f6`), soft violet (`#8b5cf6`), cyber cyan (`#06b6d4`, `#22d3ee`), and subtle magenta accents.
- **Glassmorphism & Depth**: Multi-layered translucent panels (`backdrop-filter: blur(16px)`), fine grid backgrounds, 1px subtle gradient borders, and soft glowing ambient orbs.
- **Micro-Interactions**: Ambient canvas neural network particles, cursor-following light, magnetic button shine, smooth text typewriter reveal, animated stat counters, and responsive tab transitions.
- **Zero-Dependency Native Architecture**: Built completely with semantic HTML5, modern CSS3 variables, and vanilla ES modules. **Requires zero build steps, zero node_modules, and zero terminal commands.**
